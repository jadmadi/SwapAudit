# SwapAudit v0.1.0

The first tagged release of SwapAudit: a Linux CLI that attributes swap, RAM, and `/tmp` tmpfs usage to processes and caches, then offers a guarded cleanup path.

## Assets

| Architecture | Asset |
| --- | --- |
| amd64 | `swapaudit-linux-amd64` |
| arm64 | `swapaudit-linux-arm64` |
| armv7 | `swapaudit-linux-armv7` |
| riscv64 | `swapaudit-linux-riscv64` |

`checksums.txt`, `checksums.txt.sig`, and `checksums.txt.pem` accompany the binaries.

## Install

Source build (works in the private repository):

```bash
git clone https://github.com/jadmadi/SwapAudit.git
cd SwapAudit
make build
make install
```

Authenticated release download (private repository):

```bash
gh release download v0.1.0 --repo jadmadi/SwapAudit \
  --pattern 'swapaudit-linux-amd64' --pattern 'checksums.txt'
sha256sum -c checksums.txt --ignore-missing
install -m 0755 swapaudit-linux-amd64 ~/.local/bin/swapaudit
```

Public release binaries, `go install`, and `swapaudit upgrade` require the repository to be public; they are pending that decision.

## Verify

```bash
./scripts/verify-release.sh v0.1.0
```

The script checks the four asset names, checksums, the amd64 version string, and the cosign signature when cosign is installed.

## Highlights

- Fail-closed orphan classification using cgroup and controlling-terminal evidence.
- Process UID ownership check before `SIGTERM`; `--all-users` is explicit.
- Orphan cleanup is opt-in: `--clean-all` excludes it; use `--include-orphaned`.
- Default audit performs no network I/O; `--check-updates` or `SWAPAUDIT_CHECK_UPDATES=1` opts in.
- One canonical support/security contact: GitHub private advisories and `contact@jadmadi.net`.
- Uncompressed, reproducible Linux binaries; ARMv7 asset naming fixed to `swapaudit-linux-armv7`.
- SHA256 checksums and cosign keyless signatures.

## Known limitations

- Linux only; uses `/proc` and Linux cgroups.
- RAM used relies on `MemAvailable` (Linux 3.14+).
- Scans `/tmp`, not `/var/tmp`.
- Agent detection covers `agy`, `devin`, `chrome-devtools`, and `antigravity`; other runtimes are not classified.
- No JSON output, package-manager package, GUI, or daemon.
- The repository is private; unauthenticated install and self-upgrade are not available until publication.
