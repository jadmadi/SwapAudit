# SwapAudit v0.2.0

The second tagged release. It adds guarded swap reclaim without a reboot, a
unified RAM and swap audit, machine-readable JSON, sampling, watch mode, and an
interactive action picker.

## Assets

| Architecture | Asset |
| --- | --- |
| amd64 | `swapaudit-linux-amd64` |
| arm64 | `swapaudit-linux-arm64` |
| armv7 | `swapaudit-linux-armv7` |
| riscv64 | `swapaudit-linux-riscv64` |

`checksums.txt`, `checksums.txt.sig`, and `checksums.txt.pem` accompany the
binaries.

## Install

Release binary:

```bash
curl -fsSL https://github.com/jadmadi/SwapAudit/releases/download/v0.2.0/swapaudit-linux-amd64 \
  -o ~/.local/bin/swapaudit
chmod +x ~/.local/bin/swapaudit
swapaudit --version
```

Install with Go:

```bash
go install github.com/jadmadi/swapaudit/cmd/swapaudit@v0.2.0
```

Source build:

```bash
git clone https://github.com/jadmadi/SwapAudit.git
cd SwapAudit
make build
make install
```

Upgrade an existing install:

```bash
swapaudit upgrade
```

## Verify

```bash
./scripts/verify-release.sh v0.2.0
```

The script checks the four asset names, checksums, the amd64 version string,
and the cosign signature when cosign is installed.

## Highlights

- Guarded no-reboot swap drain: `swapaudit reclaim` computes feasibility from
  available RAM and a reserve, drains one device at a time, restores it before
  the next, and emits a JSON receipt.
- Optional page-cache reclaim with `--drop-caches`.
- Unified RAM and swap audit with reconciled header totals and explicit
  residual rows.
- Versioned `--json` snapshot for scripts, statuslines, and CI.
- `sample` and `watch` modes with rates, attribution, and threshold
  notifications.
- Interactive four-tier action picker with typed confirmation.
- Agent-aware cleanup for OpenCode, Muse, Antigravity, Devin, and MCP servers.
- README restructured to answer what the tool does before the details.

## Privacy and network

The default audit makes no network requests. `--check-updates` or
`SWAPAUDIT_CHECK_UPDATES=1` performs one request to the GitHub release API.
`swapaudit upgrade` downloads a release. There is no telemetry and no account.

## Known limitations

- Linux only; uses `/proc` and Linux cgroups.
- Scans `/tmp`, not `/var/tmp`.
- Cache cleanup does not yet inspect open file descriptors, process working
  directories, or file-backed mappings.
- Agent detection covers a fixed runtime list plus MCP heuristics, not every
  agent.
- No package-manager package, GUI, or daemon.

## Known changes

- Runtime detection and default tmp patterns for an unvetted third-party AI CLI
  were removed.
